# Task 10: Blockchain Prototype Agents

This file defines specialized agents for the Blockchain Prototype project.

## Agents

### BlockchainExpert

**Expertise**: Blockchain, proof-of-work, cryptography, ECDSA signatures, P2P networking, consensus
**When to invoke**:

- Implementing or debugging blockchain core logic
- Working with proof-of-work mining and difficulty adjustment
- Understanding transaction signing and verification
- Debugging wallet key management and balance tracking
- Implementing or troubleshooting P2P peer discovery
- Working with Merkle trees and block validation
- Debugging consensus issues between nodes

**Capabilities**:

- Understand blockchain data structures and validation
- Work with ECDSA cryptography and digital signatures
- Implement mining algorithms and difficulty adjustment
- Debug P2P gossip protocols and peer communication
- Optimize transaction throughput and block creation
- Implement UTXO-based balance tracking
- Create multi-node simulations and test scenarios

---

## Quick Start

To invoke the BlockchainExpert agent:

```
@BlockchainExpert: [your question about blockchain implementation]
```

Example:

```
@BlockchainExpert: How does the proof-of-work difficulty adjustment work, and how can I make mining faster?
```
