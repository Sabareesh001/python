# Task 8: Real-Time Data Streaming Dashboard Agents

This file defines specialized agents for working with the Real-Time Data Streaming Dashboard project.

## Agents

### DashboardExpert

**Expertise**: FastAPI WebSocket servers, real-time data streaming, browser-based dashboards
**When to invoke**:

- Building or debugging the FastAPI/Uvicorn server
- Working with WebSocket connections and real-time updates
- Fixing Chart.js frontend visualization issues
- Optimizing sensor data simulation and windowed aggregations
- Troubleshooting connection/communication issues

**Capabilities**:

- Understand FastAPI async/await patterns and WebSocket handling
- Debug sensor simulator and aggregation logic
- Optimize real-time data push performance
- Fix frontend JavaScript and CSS
- Implement alert system enhancements

---

## Quick Start

To invoke the DashboardExpert agent:

```
@DashboardExpert: [your question about the dashboard or streaming implementation]
```

Example:

```
@DashboardExpert: The WebSocket connection is dropping frequently. How can I improve reliability?
```
