# Task 9: Plugin Architecture Agents

This file defines specialized agents for the Plugin Architecture with Dynamic Module Loading project.

## Agents

### PluginArchitectureExpert

**Expertise**: Plugin systems, dependency resolution, dynamic module loading, Python metaclasses
**When to invoke**:

- Designing new plugin types or plugin interfaces
- Working with dependency resolution and topological sorting
- Implementing plugin lifecycle hooks (activate/deactivate)
- Debugging plugin discovery and loading issues
- Adding new plugins to the system
- Troubleshooting plugin initialization order problems

**Capabilities**:

- Understand PluginBase interface patterns
- Implement dependency graphs and resolution algorithms
- Design extensible command/theme/formatter registries
- Debug dynamic module imports and class detection
- Optimize plugin loading performance
- Create sandboxed plugin execution environments

---

## Quick Start

To invoke the PluginArchitectureExpert agent:

```
@PluginArchitectureExpert: [your question about plugin design or implementation]
```

Example:

```
@PluginArchitectureExpert: How do I create a new plugin that depends on multiple other plugins?
```
